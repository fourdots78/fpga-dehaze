# 模板校准工具

项目实际使用的表为project/cam2dvi/src/sign_templates.vh；该表已参与74C3构建。tools/calibration保留不含本机私有路径的Python参考模型、FFD8种子表、儿童/行人的牌面裁剪和再生成脚本。

可选依赖为NumPy、Pillow，普通Gowin编译不需要Python。运行regenerate_templates.py会在工具目录生成generated_templates.vh并检查88个模板及类别是否与已验证数据一致，不覆盖工程表。

参考模型模拟已有15×15增强、预览量化、黄色定位和掩码采样；不是神经网络训练。种子64个模板包含易滑校准，随后补充儿童12个、行人12个。施工仍仅作为拒识参考。照片派生数据不等于独立实拍准确率。

修改牌面或阈值后应重新检查候选、类别混淆、完整链路及布局布线，再生成新的版本和验证记录，不得复用74C3的结果。
