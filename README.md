# FPGA 图像去雾与四类黄色警示牌识别

最终版本 74C3，2026-11-04。团队已反馈项目完成；编译、RTL 验证与 SRAM 下载证据保存在 validation。硬件由 Tang Mega 138K Pro（GW5AST-138B）及双目转接板组成，当前使用 DVP1 单路采集。

## 功能

- 原图与增强图左右同屏，1280×720 输出，15×15 暗通道处理。
- 识别注意危险、注意行人、注意儿童、易滑四类黄色警示牌，多帧确认后框选并自动抓拍原图。
- S1 单击切换右屏原图/增强，双击手动抓拍，长按约 1 秒清除抓拍和计数。单击约等待 0.3 秒。S0 为复位键。
- 手动抓拍只显示“手动抓拍”，不自动赋予识别类别；右下角调试图块已隐藏。
- 施工不作为输出类别。88 个内部模板中，72 个用于四类目标，16 个旧施工模板仅作拒识参考。

## 快速开始

1. 解压到稳定目录，推荐英文路径；安装 Gowin EDA V1.9.12.04 x64 及适用于该器件的开发环境。
2. 在包根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\verify.ps1`，核对交付文件完整性。
3. 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup.ps1`，把工程目录映射为 T:。如果 T: 已用于其他目录，脚本会退出，不会删除已有映射。
4. 在 Gowin IDE 打开 `T:\cam2dvi\cam2dvi.gprj`。顶层为 top，器件为 GW5AST-LV138FPG676AES。也可运行 tools/build.ps1 并通过 -GowinExe 指定 gw_sh.exe 完整路径。
5. 编译生成 `project/cam2dvi/impl/pnr/cam2dvi.fs`。已有最终码流可直接用于验证，详见 docs/BUILD_AND_DOWNLOAD.md。

保留已验证源码中的 T:/ 引用，源码与 74C3 构建清单逐字节一致。设置映射即可读取字库、模板与增益表，无需修改算法或安装原作者电脑上的 D:/、E:/ 软件目录；第三方 IP 头部的这些历史路径是注释。

## 已有验证与边界

87 组识别回归、686080 个 OSD 像素检查及四组完整 720p 链路验证通过。每组链路检查 3686400 个有效像素、同步、确认、框选和原图抓拍。最后一次布局布线在继承约束下 Setup/Hold 违例均为 0，最差 Setup 裕量 0.417 ns；摄像头相关普通布线时钟警告仍保留。

这些回归包括照片变换及合成输入，不等于独立摄像头数据集准确率。unknown_checker_g100_b7 在基线和最终版均可能误报为注意危险，回归对这一项检查保留行为，不表示全部负样本正确拒绝。未提供功耗、端到端时延或长期稳定性的独立统计值。

这是固定图例原型，不包含双目测距、语音播报、去雨、车牌 OCR 或云端功能。当前只完成 SRAM 临时下载，断电后会加载此前 Flash 程序；Flash 持久化属于单独操作。
